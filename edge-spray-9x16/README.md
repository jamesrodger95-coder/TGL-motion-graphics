# EDGE® — 10-second vertical reel (9:16)

**Film:** [`out/edge-spray-reel-9x16.mp4`](out/edge-spray-reel-9x16.mp4) · 1080×1920 · 60 fps · 10.0 s · stereo AAC

Made to the "Value" brief: a bold, punchy and fun film for EDGE® grip spray
(https://www.edgespray.com/), in which every message stays readable. It uses
the site's assets as gathered for the landscape film
([`../edge-spray/`](../edge-spray/README.md)): the 2 oz Grip Spray, the
traced wordmark, neon `#e2e319` on `#0a0a0a`, and the stand-in faces Saira
and JetBrains Mono.

| Time     | Beat     | What happens                                                                                                                                   |
| -------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 0 – 3.0  | Headline | **SPRAY / TO / PLAY.** (the bottle's own line), word by word, the last on the music's first 808 slam.                                          |
| 3.0 – 7  | Product  | The Grip Spray lands on the next slam, backlit. Over it is the site's number, **+25% GRIP**, and a _Lab-proven_ tag, held from 3.9 s to 6.8 s. |
| 7.0 – 10 | Action   | The wordmark, edgespray.com and **SHOP NOW**, the last landing on the track's final hit, held to the end.                                      |

**Motion.** Each entrance is a quick scale-up that settles with one small
overshoot (at most 4%). There are no carousels, lineups or charts. Nine words
are on screen in all.

**Sound.** The landscape film's track (a Lyria 3.5 hip-hop instrumental,
already generated). This cut is its last ten seconds, one continuous piece
placed so its 808 slams land at 0.58 s and 3.02 s. Over it are the spray's
hiss as the bottle lands and a boom under the wordmark.

```bash
npm run edge-spray-9x16:build   # soundtrack -> frames -> MP4
```
