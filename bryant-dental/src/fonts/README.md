# Fonts

bryant.dental sets its type in **Neue Haas Grotesk Display**, served through an
Adobe Fonts kit licensed to that domain. The kit is not copied here.

The film uses **TeX Gyre Heros** (Bold and Regular), a free, redistributable
face from the same Helvetica / Neue Haas Grotesk lineage, released by the GUST
e-foundry under the GUST Font License. The "Bryant Dental" wordmark itself is
not typeset: it is the site's own vector artwork (`../brand/bd-logo.svg`).

To match the site exactly, drop licensed Neue Haas Grotesk Display files into
this folder and point `--bd-font` in `../styles.css` at them.
